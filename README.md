# Graanit Portfolio

Modern, responsive portfolio website for a Web3 Content Creator & Builder.

## Features

- Modern Design - Clean, professional look with black and white futuristic theme
- Fully Responsive - Looks great on all devices (desktop, tablet, mobile)
- Smooth Animations - Subtle scroll animations and hover effects
- Dark Theme - Black background with white accents and red highlights
- Fast Performance - No heavy frameworks, pure HTML/CSS/JS
- SEO Optimized - Meta tags and Open Graph support
- Easy to Customize - Well-organized code with CSS variables

## Project Structure

```
portfolio/
```

## Getting Started

### Option 1: Local Development

1. Clone or download this repository
2. Open `index.html` in your browser
3. That's it! No build process required.

### Option 2: Live Server (Recommended)

If you have VS Code with Live Server extension:

1. Right-click on `index.html`
2. Select "Open with Live Server"
3. Your browser will open automatically with hot-reload enabled

## Deployment

### GitHub Pages (Free)

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select your branch and save
4. Your site will be live at `https://yourusername.github.io/portfolio`

### Netlify (Free)

1. Drag and drop this folder to [Netlify Drop](https://app.netlify.com/drop)
2. Your site will be live instantly

### Vercel (Free)

1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project directory
3. Follow the prompts

## Customization

### Change Colors

Edit the CSS variables in `css/style.css`:

```css
:root {
    --dark-bg: #000000;            /* Background color */
    --dark-card: #111111;          /* Card background */
    --text-primary: #ffffff;       /* Main text color */
    --text-secondary: #aaaaaa;     /* Secondary text */
    --accent-color: #ff0000;       /* Accent color */
}
```

### Update Content

Edit `index.html`:

- **Hero Section**: Update your name and tagline
- **About Section**: Add your story and details
- **Projects Section**: Add your real projects with screenshots
- **Contact Section**: Update your social links

### Add Your Photo

Replace the avatar image in the Hero section:

```html
<div class="avatar">
    <img src="images/your-photo.jpg" alt="Your Name" class="avatar-image">
</div>
```
